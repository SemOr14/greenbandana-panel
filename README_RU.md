# GreenBandana — прошивка 1.2.1, панель 1.2.5

## Исходники и сборка

- В корне репозитория — действующая панель GitHub Pages: `index.html`, `app.js`, `style.css`, `sw.js` и `firmware.bin` для обновления по Bluetooth.
- В `firmware/src` и `firmware/include` — исходники ESP32-S3; `firmware/platformio.ini` закрепляет платформу и библиотеки. Собрать приложение: `python -m platformio run -d firmware`.
- В `docs` — схемы, их исходные скрипты и таблица соединений. В `tests` — исходники прежних проверок; отчёт `VALIDATION_RU.md` относится к версии 1.1.0.
- В `legacy` — прежняя автономная HTML-панель и старый скрипт USB-прошивки. Эти файлы сохранены как история проекта, для текущей версии используйте корень репозитория.

Служебные файлы сборки `.pio` и старые готовые образы не опубликованы. Текущий `firmware.bin` в корне — образ приложения версии 1.2.1 для обновления через сайт.

## Обновление 1.2.0

- Удержание обеих кнопок 3 секунды даёт короткую красную вспышку и открывает на 60 секунд вход без пароля для первого подключившегося телефона. Открытая сессия остаётся рабочей после истечения окна до отключения BLE.
- После физического входа ключ сохраняется в браузере, если отмечено «Запомнить». Удержание обеих кнопок 8 секунд меняет ключ, сбрасывает Bluetooth-привязки и старый сохранённый доступ.
- В панели доступны три своих режима, каждый с восемью редактируемыми кадрами. Рисунок, цвета и кадры записываются прямо в энергонезависимую память банданы. Скорость, число кадров и реакция на громкость/басы настраиваются в панели.
- Добавлена передача новой прошивки по BLE для будущих алгоритмов. Запуск обновления требует физического удержания обеих кнопок 3 секунды и начала передачи в течение 60 секунд. Само обновление может продолжаться дольше. USB-порт герметизировать только после успешной проверки хотя бы одного обновления на устройстве.
- Адрес панели: https://semor14.github.io/greenbandana-panel/. Прошивка для кнопки «Обновить с сайта» хранится в этом же репозитории как `firmware.bin`.

## Как работают обновления и свои режимы

- Рисунки трёх режимов «Своя» редактируются на сайте и записываются по Bluetooth в энергонезависимую память ESP. Для смены их цветов, кадров, скорости или реакции на звук новая прошивка не нужна. Параметры существующих эффектов тоже меняются с сайта.
- Новый алгоритм сначала добавляется в исходный код прошивки. Затем собирается новый `firmware.bin` и публикуется вместе с панелью на GitHub Pages.
- При нажатии «Обновить с сайта» браузер скачивает этот файл через интернет. Пользователь должен быть авторизован по Bluetooth и удержать обе кнопки банданы 3 секунды до красной вспышки. Начать передачу нужно в течение 60 секунд; завершаться она может дольше.
- Браузер передаёт файл небольшими частями по BLE. ESP записывает его в область обновления flash, проверяет завершение записи и перезагружается. Уже сохранённые настройки и кадры находятся отдельно и должны сохраниться. Полный цикл на собранной бандане пока не проверен, поэтому USB-порт нельзя герметизировать до удачной пробной установки.

## Доступ после обновления 1.2.1

В новой версии фиксированного пароля нет. После установки прошивки удерживайте обе кнопки 8 секунд: ESP создаст случайный ключ и удалит старые Bluetooth-привязки. Затем подключитесь к панели, удержите обе кнопки 3 секунды до красной вспышки и нажмите «Проверить окно настройки». Браузер запомнит новый ключ на этом устройстве. После сброса привязки Android может понадобиться удалить старую GreenBandana в настройках Bluetooth телефона.

Панель 1.2.5 также показывает приблизительный ток от аккумулятора и прогноз времени работы. Для установленной 18650 исходно указана заявленная ёмкость 2500 мА·ч; её можно изменить в разделе «Аккумулятор и питание». Расчёт использует отображаемые цвета 31 светодиода, допущение 150 мА для платы и микрофона при 5 В и КПД преобразователя 85%. Прогноз основан на среднем потреблении за последние 10 минут подключения панели; это не измерение тока.

Прошивка ESP32-S3 SuperMini и браузерная BLE-панель для INMP441 и 31 WS2812B.
Матрица 6–6–7–6–6, змейка, вид снаружи. Wi-Fi не используется.
Линия данных ленты: GPIO7 → резистор 330 Ом → DIN, напрямую с логикой 3,3 В. Схема обновлена по выбору пользователя; прошивка не менялась.

## Сборка и прошивка

Предпочтительный путь: открыть папку `firmware` в VS Code с расширением PlatformIO IDE, нажать Build, затем Upload.
Или установить Python и выполнить из папки проекта:

```sh
python -m pip install platformio
python -m platformio run -d firmware
python -m platformio run -d firmware -t upload --upload-port COM5
python -m platformio device monitor -d firmware --port COM5 --baud 115200
```

Вместо COM5 указать порт своей ESP. На Linux он имеет вид `/dev/ttyACM0`.
Цель сборки — S3, 4 МБ flash, DIO, PSRAM не используется. Выбранный профиль DevKitC задаёт процессор и компоновку памяти, а не расположение контактов: GPIO назначены явно в `src/main.cpp`.

При прошивке через USB отключить внешний провод +5 В от ESP. Не подавать 5 В на контакт 3V3.
Если порт прошивки не появляется: удерживать BOOT, нажать и отпустить RESET, затем отпустить BOOT. После прошивки нажать RESET.
Не ставить произвольные новые версии библиотек: проект проверяется с Arduino-ESP32 2.0.17 и версиями из `platformio.ini`.

## Как открыть панель с телефона

1. Скопировать **содержимое** папки `web` на HTTPS-хостинг, например в `/bandana/` своего сайта. Получится `https://ваш-домен/bandana/`. Это пример пути, опубликованного адреса этот архив не создаёт.
2. Открыть страницу в Opera Android. Если браузер не предоставляет Web Bluetooth, использовать Chrome Android. Системные разрешения Bluetooth / «Устройства поблизости» должны быть разрешены.
3. Первую загрузку страницы выполнить с интернетом. Сервис-воркер сохраняет файлы для последующих открытий без интернета; не очищать данные сайта. Ярлык на главный экран необязателен.
4. Включить маску. Удержать обе кнопки управления 3 секунды: откроется окно назначения первого пароля на 60 секунд.
5. Нажать «Подключить», выбрать `GreenBandana`. Если Android предложит сопряжение — разрешить.
6. Назначить пароль минимум из 8 символов. Флажок «Запомнить» сохраняет производный ключ доступа в этом браузере. Сама ESP проверяет авторизацию перед командами.
7. При следующих подключениях нажать «Подключить»; сохранённый доступ применяется автоматически. Выбор устройства или повторное разрешение браузер может запросить снова.
8. После настройки нажать «Сохранить в маске». До этого настройки эффектов и состав основного круга действуют в оперативной памяти; настройки BLE-доступа сохраняются сразу. Последний обычный режим дополнительно запоминается автоматически через 1,5 с после его смены.

Открытый с диска `index.html` подходит для демо, а для надёжной работы BLE и офлайн-режима нужен HTTPS. Контроллер не раздаёт эту страницу через Bluetooth: браузер загружает интерфейс с сайта, затем общается с ESP по BLE. Сеть и VPN менять не требуется. При сворачивании браузера Android может прервать BLE; эффекты маски продолжат работать самостоятельно.

В панели «Демо» показывает имитацию звука и заряда. Это проверка интерфейса, а не точная симуляция всех фильтров прошивки. Реальный предпросмотр приходит с ESP примерно раз в секунду; сама матрица обновляется до 40 кадров/с.

## Кнопки

| Кнопка | Действие |
|---|---|
| S1 | Питание, с фиксацией |
| S2 / GPIO8: коротко | Следующий отмеченный основной режим по кругу |
| S3 / GPIO9: коротко | Войти в режим смыкания / вернуться в предыдущий обычный режим |
| S2: держать 0,7 с | Сердечко на 4 с, затем возврат к текущему эффекту |
| S3: держать 0,7 с | Действие не назначено |
| S2 + S3: держать 3 с | Окно назначения первого пароля на 60 с |
| S2 + S3: держать 8 с | Сброс доступа и Bluetooth-привязок, назначение нового пароля; настройки света остаются |

Окно 3 с не отменяет существующий пароль. Чтобы изменить забытый пароль, нужен сброс 8 с. Комбинация подавляет короткие действия при отпускании.

## Основные режимы и возврат

В панели под режимами есть флажки «Основные». Первая кнопка листает только отмеченные режимы по порядку списка, с возвратом к первому. Можно оставить один режим; пустой список недопустим. Любой эффект также можно выбрать напрямую в панели, даже если он исключён из круга.

Смыкание не включается в основной круг: вторая кнопка включает его как отдельный режим. Вход означает зелёное поле и ожидание настроенного ора, а не немедленное сжатие. Повторное нажатие возвращает обычный эффект, работавший перед входом. Длительное первое нажатие по-прежнему показывает сердечко на 4 с.

Название текущего режима и режим возврата отображаются на телефоне. Изменения от физических кнопок приходят с телеметрией примерно раз в секунду. Первая кнопка в режиме смыкания выходит в следующий основной относительно запомненного обычного эффекта.

Последний обычный режим автоматически записывается после 1,5 с без переключений. После включения питания восстанавливается он; смыкание автоматически не включается. Состав основного круга и параметры эффектов сохраняются кнопкой панели «Сохранить в маске».

## Эффекты

0. **Рот**: огибающая громкости открывает силуэт, баланс низких и высоких частот меняет ширину. Основной цвет постепенно переходит в цвет громкого звука после регулируемого порога. Это стилизация, а не распознавание фонем.
1. **Полосы**: горизонтальные линии расходятся вверх и вниз, цвет реагирует на громкость.
2. **Эквалайзер**: частотные столбики. Внутри анализируются восемь диапазонов; из-за разреженной матрицы часть отображается на соседних позициях.
3. **Волна**: движущаяся линия, размах зависит от звука.
4. **Басы**: размер светящейся области, яркость и цвет зависят от энергии выбранного басового диапазона.
5. **Смыкание**: зелёное поле сужается слева и справа к центру и переходит в красный. Центральный диод — №15.
6. **Цвет**: вся маска выбранного цвета.
7. **Дыхание**: плавное изменение яркости.
8. **Басовый импульс**: кольцо от центра по выраженному нарастанию баса. Это детектор басового удара, а не точное определение BPM.
9. **Пламя**: отдельное поле тепла 7×5, нагрев снизу, перенос вверх и затухание. Работает без микрофона. Настраиваются цвет углей, цвет горячих языков, интенсивность, затухание и общая скорость.
10. **Светомузыка**: низкие частоты окрашивают преимущественно нижнюю часть, средние — центр, высокие — верхнюю. Цвета плавно смешиваются на границах; громкость влияет на яркость. Настраиваются три цвета и чувствительность. Это реакция на спектр, а не распознавание трека или точного BPM.

Сердечко накладывается на любой режим на 4 секунды. Во время него внутреннее состояние эффекта продолжает обновляться.

### Логика смыкания

Срабатывание требует превышения порога dBFS и достаточной доли энергии в заданном диапазоне в течение настроенного времени. Начальные настройки: −14 dBFS, диапазон 100–1800 Гц, доля 0,35, длительность 200 мс. Это отправные настройки для калибровки, не универсальный порог концерта.

При срабатывании запоминаются громкость и распределение энергии по восьми полосам. Смыкание занимает 350 мс. Затем красное состояние держится минимум 15 с (регулируется от 12 до 15 с). Раскрытие начинается, когда **одновременно**:

- прошла минимальная выдержка;
- громкость отличается от исходной не менее чем на заданное число дБ (по умолчанию 7);
- частотный состав отличается достаточно сильно (косинусное расстояние, по умолчанию 0,20);
- оба изменения устойчивы в течение 1 с.

Если хоть один признак не изменился — красное состояние сохраняется без ограничения времени. По умолчанию раскрытие длится 1,8 с. Свежий ор после спада сигнала может прервать раскрытие. Кнопка панели «Проверить смыкание» запускает этот сценарий вручную с текущим звуком в качестве образца.

### Что на этой матрице ограничено

Сердечко и рот — условные пиксельные силуэты; подробная артикуляция и текст здесь не получатся. Волна и кольцо выглядят дискретно, поэтому используется плавное изменение яркости соседних позиций.

Пламя на пяти рядах остаётся стилизованным. Бегущие символы и переключение эффектов высотой голоса пока не включены: читаемость символов и надёжность голосовых команд на концерте требуют проверки; назначения «низкий/средний/высокий» не согласованы.

## Первая проверка после пайки

1. Без подключённой электроники выставить MT3608 ровно на 5,0 В мультиметром. Проверить полярность.
2. Проверить питание ESP, затем подключить микрофон и ленту. Питание рядов — параллельно, данные — змейкой. Не пропускать питание ленты через плату ESP.
3. Начальные яркость 90/255 и лимит ленты 900 мА. Лимит — расчётная оценка по цветам, а не аппаратное измерение или защита MT3608.
4. В панели включить номера. Нажатие на диод предпросмотра при подключённой маске зажигает соответствующий физический диод тусклым белым на 1,5 с. Проверить №0, 5, 6, 11, 12, 18, 19, 24, 25, 30.
5. Сравнить красный/зелёный/синий цвета. Порядок каналов выбран GRB. Если реальные цвета перепутаны, проверить тип ленты и параметр `NEO_GRB`.
6. Проверить речь: индикатор dBFS должен меняться, низкий звук должен увеличивать басовую реакцию. Если линия стоит около −160 dBFS, проверить VDD, SCK, WS, SD и L/R микрофона. Речь идёт об уровне цифрового сигнала, не SPL.
7. Перегруз INMP441 не устраняется ползунками усиления. Программа показывает цифровые пики, близкие к пределу; аналоговое искажение микрофона может начаться раньше. Для громкого концерта важны положение и акустическое оформление микрофона.
8. На месте настроить порог ора по индикатору, затем долю энергии. Слишком широкий диапазон может срабатывать на всю музыку.
9. Увеличивать яркость с проверкой нагрева MT3608, просадки питания и тока аккумулятора. Возможность постоянного белого на полной яркости для этого модуля не подтверждена.
10. Сверить напряжение панели с мультиметром и при необходимости изменить поправку. Проценты заряда ориентировочные, особенно под нагрузкой. Если делитель не подключён, панель должна показывать «нет измерения».

## Зарядка

Заряжать через USB-C TP4056 при выключенном S1. Micro-USB MT3608 является входом преобразователя, а не зарядкой аккумулятора. Ток TP4056 должен подходить установленной 18650; её заявленная ёмкость 2500 мА·ч ещё требует проверки. Эта версия не включает питание во время зарядки: для этого нужен узел power-path. При выключенной ESP зарядка не отображается на телефоне.

## Сбои подключения

- Убедиться, что это Opera Android, HTTPS и разрешён Bluetooth. Для сравнения попробовать Chrome Android.
- После сброса привязок на ESP при необходимости удалить старую `GreenBandana` в настройках Bluetooth Android и сопрячь заново.
- При разрыве нажать «Подключить». Настройки эффектов и работа кнопок от телефона не зависят.
- Случайный наблюдатель не может управлять без авторизации. Применяются шифрование BLE Secure Connections и проверка пароля; первый обмен использует физическое окно настройки. Устройство без экрана использует Just Works и не обещает защиту от активного посредника при первичном сопряжении.

## Обновление с 1.0.0

Обновить и прошивку, и содержимое папки `web` на хостинге. Затем перезагрузить страницу; если остаётся старый интерфейс, закрыть вкладку и открыть заново с интернетом. Полное стирание flash не требуется: пароль, палитры и прежние настройки должны сохраниться. Старые номера эффектов 0–8 не изменены; новые — 9 и 10.
