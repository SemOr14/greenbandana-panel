# Проверка версии 1.1.0

## Выполнено

- Полная сборка PlatformIO для ESP32-S3 с Arduino-ESP32 2.0.17, NimBLE-Arduino 1.4.3, ArduinoJson 6.21.5, Adafruit NeoPixel 1.12.3.
- Занято 588 545 байта flash приложения (44,9% раздела), статическая RAM 36 384 байт (11,1%).
- Сформирован объединённый образ с загрузчиком, таблицей разделов и приложением; проверен заголовок esptool.
- Тесты C++ с AddressSanitizer и UndefinedBehaviorSanitizer (проверка утечек отключена из-за ограничения среды): минимальная выдержка смыкания, бесконечное красное при неизменном оре, требование изменения обоих признаков, фильтрация коротких провалов, переход обратно в зелёный, переполнение millis(), FFT известного сигнала, цифровой перегруз, раскладка всех 31 индекса и программный лимит тока.
- Новые C++-тесты: круг из выбранных режимов, возврат после полного круга, единственный режим, запрет пустого списка и смыкания в круге, вход/выход из смыкания с точным возвратом, выход первой кнопкой, пламя без микрофона, изменение его кадров и распределение тепла, молчание и раздельные частотные цвета светомузыки.
- Панель: флажки основных режимов, запрет пустого круга, обе новые кнопки в демо, сохранение маски режимов через BLE, синхронизация текущего режима и списка по входящей телеметрии.
- Node: проверка синтаксиса app.js и sw.js.
- JSDOM: инициализация интерфейса, одиннадцать режимов, сердечко и ручной запуск, независимые эталонные PBKDF2/HMAC-векторы, первое назначение пароля, BLE-протокол с фрагментацией 18/7 байт, передача и сохранение настроек, повторное подключение по сохранённому ключу, отображение аккумулятора и перегруза.
- Схема PNG просмотрена визуально; таблица соединений согласована с GPIO в прошивке.

## Не проверено на физическом устройстве

- Микрофон и электрическое питание платы, передача WS2812B и порядок цветов конкретной ленты.
- Реальный радиоканал и системное BLE-сопряжение в Opera / Android, восстановление соединения после сна телефона, офлайн-кэш на телефоне.
- Нагрев и максимальная мощность MT3608, просадки напряжения, ток и время автономной работы выбранного аккумулятора.
- Калибровка напряжения и точность процентов заряда.
- Пороги ора на реальном концерте, различимость силуэтов через ткань.
- Полноценный браузерный прогон Playwright не выполнен: загрузка браузера в среде не завершилась. Проверка DOM и протокола выполнена в JSDOM, аппаратный BLE имитировался.

## Повторить тесты

Из корня проекта:

```sh
python -m platformio run -d firmware
g++ -std=c++17 -Wall -Wextra -Werror -Wno-misleading-indentation -fsanitize=address,undefined -I firmware/include tests/engine_test.cpp -o engine_test
ASAN_OPTIONS=detect_leaks=0 ./engine_test
cd tests
npm install
npm test
```

`browser_test.cjs` — дополнительный тест для среды с установленным Playwright Chromium. Он запускается при работающем `python -m http.server 8765 --directory web`. Это не заменяет тестирование BLE на телефоне.
