# Документация компонентов и API

- ESP-IDF 4.4, I2S на ESP32-S3: https://docs.espressif.com/projects/esp-idf/en/v4.4/esp32s3/api-reference/peripherals/i2s.html
- ESP32-S3 ADC: https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/adc/index.html
- NimBLE-Arduino, закреплённая версия: https://github.com/h2zero/NimBLE-Arduino/tree/1.4.3
- Web Bluetooth: https://developer.chrome.com/docs/capabilities/bluetooth
- NeoPixel: https://learn.adafruit.com/adafruit-neopixel-uberguide/best-practices
- SN74AHCT1G125: https://www.ti.com/lit/ds/symlink/sn74ahct1g125.pdf
- INMP441: https://invensense.tdk.com/wp-content/uploads/2015/02/INMP441.pdf

Фактические API проверены также по исходникам зависимостей, загруженным PlatformIO при сборке. Номер платформы и версии библиотек закреплены в firmware/platformio.ini.
