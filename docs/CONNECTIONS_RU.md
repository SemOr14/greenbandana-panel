# Соединения

Схема рассчитана на 1S Li-ion/LiPo 3,7 В (4,2 В после заряда) и платы с присланных фото. GPIO — номера сигналов, а не номера ножек.

| Откуда | Куда |
|---|---|
| АКБ + / − | TP4056 B+ / B− |
| TP4056 OUT+ | S1 (с фиксацией), затем MT3608 IN+; эту точку после S1 называем VBAT_SW |
| TP4056 OUT− | MT3608 IN− и общая GND_SYS |
| MT3608 OUT+, настроенный на 5,0 В | +5V всех рядов ленты, вход 5V платы ESP |
| MT3608 OUT− | GND ленты, ESP, микрофона, кнопок и измерения АКБ |
| ESP 3V3 | INMP441 VDD |
| ESP GPIO4 | INMP441 SCK |
| ESP GPIO5 | INMP441 WS |
| INMP441 SD | ESP GPIO6 |
| INMP441 L/R | GND_SYS (выбран левый I2S-канал) |
| INMP441 SD | Через 100 кОм на GND_SYS |
| ESP GPIO7 | Через резистор 330 Ом непосредственно на DIN первого диода |
| GPIO8 | S2 без фиксации, другой контакт кнопки на GND_SYS |
| GPIO9 | S3 без фиксации, другой контакт кнопки на GND_SYS |
| VBAT_SW | R3 100 кОм, затем GPIO1 |
| GPIO1 | R4 100 кОм на GND_SYS и C4 100 нФ на GND_SYS |

Лента подключается непосредственно к GPIO7 через один последовательный резистор 330 Ом. Резистор расположить рядом с DIN первого диода, провод сделать коротким; GND ESP и ленты общий.

## Дополнительные детали

| Деталь | Количество | Примечание |
|---|---:|---|
| 330 Ом | 1 | Возле DIN первого диода |
| 100 кОм, 1% | 3 | Два делителя АКБ, один подтяжки SD микрофона |
| 100 нФ | 2 | У микрофона и входа GPIO1; на микрофонном модуле конденсатор может уже быть |
| 1000 мкФ / 10 В | 1 | Между +5V и GND возле входа ленты, с соблюдением полярности |
| S1 с фиксацией | 1 | Рассчитан на ток от АКБ; подбор после выбора элемента и измерения нагрузки |
| S2, S3 без фиксации | 2 | Внутренние подтяжки ESP, отдельные резисторы не нужны |

## Змейка, вид спереди на надетую маску

| Ряд сверху | Слева направо: индексы | Направление данных |
|---|---|---|
| 1 | 0, 1, 2, 3, 4, 5 | Слева направо |
| 2 | 11, 10, 9, 8, 7, 6 | Справа налево |
| 3 | 12, 13, 14, 15, 16, 17, 18 | Слева направо |
| 4 | 24, 23, 22, 21, 20, 19 | Справа налево |
| 5 | 25, 26, 27, 28, 29, 30 | Слева направо |

Между рядами DOUT последнего диода предыдущего ряда идёт в DIN первого следующего. Питание каждого ряда подключается параллельно к +5V и GND. На физической ленте ориентироваться по стрелкам DIN → DOUT. Со стороны лица вся раскладка выглядит зеркально.

Все земли нагрузки подключать к OUT− защищённого зарядного модуля. Не соединять их напрямую с B− в обход защиты. Делитель АКБ измеряет точку после S1, **до** повышения напряжения. Плата ESP питается от 5V, микрофон — от 3V3.
