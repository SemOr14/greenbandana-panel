# Предыдущие исходники

`bandana_panel.html` — старая автономная версия панели. Действующая панель размещена в корне репозитория.

`flash_windows.bat` — прежний USB-скрипт для объединённого образа, который здесь не опубликован. Для текущей прошивки используйте исходники в `firmware/` и панель обновления.
